# Stable Assets

USDGLO and Helios are examples of stable assets. These assets are redeemable for $1 USD as long as the redemption pool is stocked or laws are enforced. USDGLO uses Brale to issue its stablecoin. Brale states that USDGLO is always redeemable 1:1 for U.S. dollars. As such USDGLO can scale to large debt ceilings with Brale handling the security of redemption. Helios on the other hand uses a smart contract vault. The stablecoins kept in this vault are redeemable for the HLSp token 1:1. However the dollar value kept in this vault varies and should not be the only consideration for HLSp debt ceiling.&#x20;

Both HLSp and USDGLO have priority in OTC deals if Azos gains controls of assets liquidated. These OTC deals and the amount that both organizations are ready to buy, help to influence the overall debt ceiling.&#x20;
