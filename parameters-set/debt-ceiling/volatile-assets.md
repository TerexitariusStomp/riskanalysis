# Volatile Assets

KLIMA and WETH are both volatile assets. The maximum debt ceilings that these assets can have currently is defined below.&#x20;

$$
D = A/2 * √ B
$$

Where&#x20;

D = Maximum Debt Ceiling

A = Available liquidity across all chains

B = Liquidated buffer



Note: Liquidity on target chain should be compared to liquidity on all chains. If the liquidity on target chain is miniscule in monetary value then the above equation should be modified.&#x20;
