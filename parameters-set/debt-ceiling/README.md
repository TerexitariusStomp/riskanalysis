# Debt Ceiling

The maximum total amount of stablecoin that can be issued or borrowed against a specific collateral type. Each collateral asset has its own debt ceiling, capping the aggregate amount of stablecoin that can be minted using that collateral. This parameter limits exposure and helps manage risk at the protocol level. For example, a debt ceiling of 40,000 AZUSD for a collateral type means no more than 40,000 AZUSD can be generated using that asset across all users. Debt ceilings are dynamically adjusted through governance. Initially conservative exposure limits are set, these can be increased as ceilings are reached.
