# Calculations

Debt ceilings for collateral assets were set conservatively so that the community can reach them together and through governance move them to a higher level. The maximum debt cieling calculations are outlined below.&#x20;

Maximum debt ceiling calculations can be found on the financial spreadsheet in the worksheets section.&#x20;

From these calculations we can see that if USDGLO and Helios were not redeemable they would not be able to receive a very high max debt ceiling. This is largely due to a lack of liquidity as well as not a very small liquidated buffer. However, as they are redeemable the maximum debt ceilings reflect that.&#x20;

Meanwhile, KLIMA and WETH are volatile however have a higher debt cieling. This is largely due to the liquidated buffer being bigger as well as having more liquidity.&#x20;

A note on WETH- the calculation was done for a single pool on Base and the actual max debt ceiling for WETH is much higher.&#x20;
