# Redeem

Assets that are always redeemable for an underlying store of value. For example Glo Dollars ability to always be redeemed for USD through Brale. When redeemable for large scale liquidations or transactions that would lead to large value lost- the assets will be redeemed. As the redemption is in fiat, the slippage is the value lost when onramping the fiat into crypto.

Helios also has a vault where Hlsp tokens can be redeemed 1:1 for USDC. However the value that lies in that vault may not be representative to the debt ceiling due to other agreements they are in with Azos.
