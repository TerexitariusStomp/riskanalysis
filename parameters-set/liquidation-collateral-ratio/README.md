# Liquidation Collateral Ratio

If a vault's value falls below the safety collateral ratio it becomes at risk of liquidation. If the vault's value continues to drop and hits the liquidation collateral ratio, then the vault is liquidated. The difference between the safety and liquidation collateral ratios is called the liquidation buffer. This liquidation buffer enables the user to have time to manage their position before it gets liquidated. If a safety ratio is set at 150% and the liquidation ratio is set at 120%, there is a further 30% of decline in vault value before the position gets liquidated (the liquidation buffer). Any position with a collateral value below $1.20 for each $1 borrowed can be liquidated. The liquidation collateral ratio is designed to protect the protocol from bad debt. The liquidation ratios ensure liquidators can operate profitably even with market slippage.
